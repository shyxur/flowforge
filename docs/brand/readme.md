# windylane brand assets

the files in this directory document the windylane visual identity and are
provided for reference only. the product domain target is `windylane.dev`.

current source assets:

- `windylane-brand-board.png` — visual brand reference
- `windylane-logo.png` — primary wordmark and emblem lockup
- `windylane-mark.png` — standalone two-node flowing lane emblem

dashboard copies used by the application live at:

- `apps/dashboard/public/brand/windylane-logo.png`
- `apps/dashboard/public/brand/windylane-mark.png`

the primary logo and standalone mark must use the same emblem. legacy assets,
if retained for history, belong only under `docs/brand/archive/` and must not be
presented as the current windylane identity.
