# Architecture decision records

An architecture decision record (ADR) captures the context, decision, and
consequences of a significant technical choice.

Accepted ADRs describe windylane's current architecture. Future changes should
add a decision that supersedes an earlier record rather than silently rewriting
the historical rationale.
